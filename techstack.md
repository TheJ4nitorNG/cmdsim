| Layer                | Technology                                               | Why                                                      |

| -------------------- | -------------------------------------------------------- | -------------------------------------------------------- |

| Language             | \*\*C# (.NET 9+)\*\*                                         | Native PowerShell ecosystem, high performance, rich APIs |

| Runtime              | .NET                                                     | Cross-platform, mature, excellent tooling                |

| CLI                  | PowerShell Module + Native Console App                   | Easy adoption and scripting                              |

| Parser               | PowerShell AST (`System.Management.Automation.Language`) | No need to write a parser                                |

| UI                   | Spectre.Console                                          | Rich terminal UI with tables, trees, progress, colors    |

| Plugin System        | MEF or AssemblyLoadContext                               | Safe dynamic loading of predictors                       |

| Serialization        | System.Text.Json                                         | Fast and built-in                                        |

| Logging              | Serilog                                                  | Structured diagnostics                                   |

| Dependency Injection | Microsoft.Extensions.DependencyInjection                 | Standard .NET pattern                                    |

| Testing              | xUnit + FluentAssertions                                 | Excellent developer experience                           |

| Benchmarking         | BenchmarkDotNet                                          | Measure simulation performance                           |

| Packaging            | PowerShell Gallery + winget + NuGet                      | Familiar distribution channels                           |
